Features

为天天出图的人做的工具

不是又一个网页生图站。PicGen 是常驻桌面的小窗，接你自己的 API，把出图、改图、找图放在一个地方。

01

悬浮小窗，不占地方

拖到屏幕边缘就停靠成一条小标签，鼠标移过去展开。可以置顶，编辑时不会自动收起。

02

多供应商自动切换

按优先级、负载、价格或速度分配任务。某一家报错或排队，自动换下一家重试。

03

多序列并行

开几个序列同时跑不同的任务，每个序列有自己的提示词、模型和参考图。

04

参考图直接 @ 引用

输入 @ 选一张参考图，提示词里出现带缩略图的标签，模型就知道"这张"指的是哪张。

05

图片工作台

画框标注要改的地方、摆放尺寸参照物、涂抹蒙版做局部修改，选好模型一键发回生成。

06

历史资产库

每张图都带着提示词保存。可以搜索、筛选、查找相似图，直接拖进 PS / AI 使用。

07

提示词优化与反推

一句话想法改写成完整提示词；拿一张图反推出可复用的提示词。

08

数据全在本地

配置、密钥、图片都存在你自己的电脑上，软件只请求你配置的接口，不收集任何数据。

FAQ

常见问题

PicGen 收费吗？

软件本身免费。出图费用由你接入的模型供应商收取，PicGen 不经手任何费用。

需要自己准备 API Key 吗？

需要。PicGen 是客户端，可以接 OpenAI、Google 官方接口，也可以接各类兼容这些接口的中转站，Key 填在设置里。

我的图片和 Key 会被上传吗？

不会。PicGen 只请求你自己配置的接口地址；相似图分析用的是内置在软件里的本地模型。

杀毒软件或 Windows 拦截怎么办？

程序没有代码签名，首次运行可能被 SmartScreen 提示。可以核对上面的 SHA-256 校验值，确认文件完整后点"更多信息 → 仍要运行"。

换电脑后历史和配置都没了？

数据在 exe 旁边的 PicGenData 文件夹里，要整个文件夹一起复制（包括里面的 Local State，否则保存的 API Key 无法解密）。

怎么升级到新版本？

把新的 exe 放到旧 exe 所在的文件夹（和 PicGenData 放在一起）运行即可，配置和历史都会保留。
